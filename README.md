# 책친구 코치

학생이 읽은 책을 바탕으로 AI 코치와 대화하며 생각을 깊게 하는 독서 코치 웹앱. 파일 하나(`index.html`)로 동작합니다.

## 교사·학부모 실행 방법 (5단계)
1. Google AI Studio(aistudio.google.com)에서 Gemini API 키를 만들어 복사합니다.
2. `index.html`을 더블클릭해 브라우저(크롬 권장)로 엽니다.
3. 오른쪽 위 **⚙️ 관리자** → 키를 붙여 넣고 **키 저장** → **연결 테스트**에서 "연결 성공"을 확인합니다.
4. 홈으로 돌아가 학생이 학년을 고르고 **새 독서 시작**을 누르게 합니다.
5. 기록은 그 기기의 브라우저에만 남습니다. 지우려면 관리자 → 전체 기록 삭제.

- 설계 결정과 이유: `context-notes.md`
- 구현·검증 체크리스트: `checklist.md`
